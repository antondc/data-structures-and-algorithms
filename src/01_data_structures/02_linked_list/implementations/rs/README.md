# Linked List in Rust

Implementing linked lists in Rust is an advanced topic due to the language's ownership system.
While it is possible and valid to implement them in this language, doing so typically requires the use of unsafe blocks, which reveals more about Rust's internals than about the data structure itself. For this reason this implementation will be skipped here.
For a detailed explanation of linked lists in Rust, refer to [Too Many Linked Lists](https://rust-unofficial.github.io/too-many-lists/).
