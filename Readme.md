# Data structures and algorithms

## Description

Ongoing effort to document most common data structures and algorithms, with implementations TypeScript, Rust and Go.

## Run

### TypeScript

    npm i
    npm run test::watch

### Rust

    cargo install
    cargo watch -x test
    cargo watch -x 'test works_with_reversed_arrays -- --nocapture'

### Golang

    go test ./... -v
